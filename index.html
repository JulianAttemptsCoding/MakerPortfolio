Iterated prisoner's dilemma tournament

repo | commit b536cb1

58 hand-written strategies, round robin, 200 rounds per match, 5% move noise. Python stdlib only.

Run: python main.py

  1. main.py:13-17
    Noise model. Each move flips with p = 0.05; this is what separates forgiving strategies from strict tit-for-tat.
  2. main.py:94-102
    Pavlov (win-stay, lose-shift), driven by the payoff matrix rather than the opponent's last move.
  3. main.py:580-593
    Round robin. Seeded, so a given seed reproduces the tournament exactly, noise included.

Crop pathogen spread forecasting (spatio-temporal GNN)

repo | commit 1ca73f0

Graph WaveNet-style model over 194 countries: predicts next-month presence of 8 crop pathogens from 24 months of IMF/FAOSTAT trade and climate anomalies. Chronological split, test 2021-01 to 2025-08: macro AUROC 0.960, AUPRC 0.785, after temperature scaling. The reported model's file was recovered from the package the training jobs ran; the README says how.

Run: pip install -e . && pytest -q # data-dependent tests skip without the zarr stores

  1. pathograph/models/stmm_gwnet_adaptive.py:325-350
    Learned adjacency: softmax(relu(E1 E2^T)) from 10-d country embeddings, top-20 per row, renormalized. Lets the model find links that border and trade graphs miss.
  2. pathograph/models/stmm_gwnet_adaptive.py:35-80
    Diffusion graph convolution: K powers of each support (border graph, its transpose, learned graph, its transpose), so risk can flow in both directions.
  3. pathograph/models/stmm_gwnet_adaptive.py:240-294
    Node features from edge tensors: bilateral trade (N x N per month) reduced to per-country inflow/outflow, per pathogen-risk channel.

Neutron energy reconstruction in the EIC zero-degree calorimeter

repo | commit ee001db

100k simulated events (50-250 GeV neutrons). Variable-length ECAL/HCAL hits compressed to fixed shower descriptors; XGBoost vs. physics baselines. Test: MAE 4.42 GeV, resolution 5.3% (two-term linear calibration: 6.21 GeV, 6.7%).

Run: pip install -e . && python scripts/05_evaluate_models.py --features data/processed/features_extended37.parquet --splits data/processed/splits.parquet # no ROOT file needed

  1. src/zdc_energy_regression/features.py:90-108
    Energy-weighted shower centroid and RMS radius.
  2. src/zdc_energy_regression/features.py:110-137
    Depth-profile features (longitudinal skew, front/back energy fraction), which is where leakage shows up.
  3. src/zdc_energy_regression/features.py:141-159
    One fixed-length row per event; ECAL fraction and log total energy across sections.

Run: npm install && npm run test && npm run typecheck

  2. src/lib/protectedApp.ts:434-461
    Every asset is checked against its SHA-256 and byte length before it can execute.
  3. tests/e2e/security.spec.ts:74-170
    Bypass attempts (deleting the gate in DevTools, editing storage, firing the shell's events, hitting endpoints directly) each asserted to grant nothing.

Cross-sectional equity model

repo | commit 0ea9a10

Per-stock causal dilated TCN (WaveNet-style) encoder, one self-attention layer across all stocks on a date, non-crossing quantile head. Beat SPY on return but not risk in its first run; fair re-tests were negative, so it was not deployed. The planned expert-aggregation layer is unbuilt (stubs). See REPORT.md.

Run: pip install -e ".[dev]" && python make.py test

  1. src/tactic/models/experts/tcn_ci.py:15-54
    Causal dilated convolutions (dilations 1-32, left-padded only), shared weights across stocks.
  2. src/tactic/models/experts/hybrid_xs.py:15-35
    Attention across the date's stocks. Removing it gives f3; f4 beats f3 (Diebold-Mariano p = 0.0099), so the signal is cross-sectional.
  3. src/tactic/validation/cpcv.py:55-103
    Combinatorial purged CV: purge train points whose label window touches test, embargo after test, to stop look-ahead leakage.

Multiplayer falling-block game

repo | live | commit ff8c3d1

Run: npm install && npm test

  1. public/engine.js:275-299
    Rotation with wall-kick tables; separate table for the I piece, none for O.

  3. public/engine.js:503-553
